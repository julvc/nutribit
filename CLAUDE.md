# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

NutriBit — calorie and weight tracker. Vite + React 19 + TypeScript + Supabase (auth + Postgres) + GitHub Pages + PWA. UI is in Spanish. See `NUTRIBIT_PLAN.md` (local, gitignored) for roadmap and pending user setup steps.

## Commands

```bash
npm run dev       # dev server at http://localhost:5173
npm run build     # tsc --noEmit && vite build → dist/
npm run preview   # serve the production build
```

No test suite or ESLint; `tsc --noEmit` in the build is the type gate.

## Architecture

- `src/App.tsx` — session state (Supabase auth listener) + tab navigation (Hoy/Historial/Peso). No router.
- `src/lib/supabase.ts` — Supabase client; exports `configOk` (false when `.env.local` is missing → App renders a setup message instead of crashing).
- `src/components/` — one file per view: `Auth`, `Dashboard` (daily meals + goal), `MealForm`, `History` (14-day chart), `Weight`. Each view queries Supabase directly with hooks; there is deliberately no global state/context.
- `src/types.ts` — row types + `todayLocal()` (client-local YYYY-MM-DD; dates are always client-side, never server `CURRENT_DATE`).
- `supabase/schema.sql` — tables `meals`, `user_profiles`, `weight_log` with RLS (`USING` + `WITH CHECK`). Run manually in the Supabase SQL Editor; there are no migrations.
- `vite.config.ts` — `base: '/nutribit/'` (GitHub Pages subpath) and the PWA manifest (generated by vite-plugin-pwa; no manual manifest.json).
- Deploy: push to `main` → `.github/workflows/deploy.yml` builds and publishes to GitHub Pages. Supabase credentials come from repo Actions secrets; locally from `.env.local` (see `.env.example`).

## Local (gitignored) tooling

`.claude/` holds project skills (`nutribit-design`: design tokens + visual iteration flow; `nutribit-roadmap`: backlog + working mode) and agents (`nutribit-ui`, `nutribit-feature`). Load the matching skill before UI work or feature planning. `NUTRIBIT_PLAN.md` (also gitignored) has the roadmap.

## Constraints

- Any date written to the DB must come from the client (`todayLocal()` or a date input), never generated server-side — timezone correctness depends on it.
- Asset paths must respect the `/nutribit/` base.
- Web must be 100% stable before any mobile-native work (Capacitor is the planned route; PWA covers mobile until then).
